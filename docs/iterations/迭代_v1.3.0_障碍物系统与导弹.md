# 迭代_v1.3.0_障碍物系统与导弹（已批准）

> 状态：**已获用户批准**（2026-09-12 用户直接下达需求）｜ 版本性质：次版本号 +0.1.0（新增玩法模块）

## 1. 需求与目标
1. **障碍物系统扩展**：管道之外加入新类型障碍物，包括可移动的怪物（Obstacle 基类扩展）
2. **导弹道具**：发射导弹攻击附近一个障碍物，**怪物优先**（为未来 Boss 战做技术铺垫：抛射物系统 + 障碍物 HP/受击接口）
3. **修复减速 bug**：减速机制（速度包/时间扭曲）导致障碍物空间密度变大——根因：管道按**帧数间隔**生成，世界减速后移动变慢但生成节奏不变。修法：改为**按滚动距离生成**

## 2. 设计方案（项目管理 Agent 定稿，用户授权方案裁量）

### 2.1 障碍物系统
- 利用现有 `Obstacle` 基类扩展，新增 `Monster` 子类：带 HP、移动模式、可被导弹锁定（`destructible` 接口，为 Boss 铺垫）
- 首批 2 种怪物（数值全部入 GameConfig）：
  - **蝙蝠怪** 🦇：从右侧飞入，正弦垂直波动，HP=1，碰撞=伤害（走统一护盾/受击链）
  - **浮游怪** 👾：从右侧飞入，以滞后追踪方式缓慢逼近小鸟的 y 坐标（追踪速度设上限，保证可躲避），HP=2
- 生成规则：开局 45s 后出现（给新手保护期），屏幕同时最多 2 只，生成位置避开管道间隙正中央（不堵死通路），按距离节奏生成
- 击杀奖励：怪物被导弹击杀掉落少量经验（+10）并有爆炸粒子反馈；碰撞管道规则不变
- 明确不做：怪物主动攻击弹幕、Boss（后续版本）

### 2.2 导弹道具 🚀
- 新道具类型加入道具表（与经验包/血包/护盾包/速度包并列，权重入配置）
- 拾取即发射：从小鸟位置向右发射 1 枚导弹，带**弱追踪**（朝目标缓慢修正弹道）
- 目标选择：范围内**怪物优先**，无怪物则选最近的可破坏障碍物；命中管道可将其炸毁（清除该管道，给通路）
- 导弹为独立实体（新建 entities/Missile.js）：速度/伤害/爆炸半径配置化；命中爆炸粒子 + 屏幕轻震动反馈
- Obstacle 基类补 HP/`takeDamage()`/`destructible` 接口（Boss 战直接复用）
- 明确不做：多枚连发、主动发射按钮、导弹能力卡（后续可作为能力加入）

### 2.3 减速密度 bug 修复（P1）
- 管道生成从"每 N 帧"改为"每 N 像素滚动距离"：SPAWN_INTERVAL(帧) → SPAWN_DISTANCE(px)（初值 90×3.0=270px），v1.2.2 的 N5 ramp 同步改为距离 ramp（270→240px，120s→300s）
- 减速（速度包/时间扭曲/慢速世界）只影响移动速度，不再改变空间密度
- 怪物生成同样按距离节奏
