1. **§4.9 保底输出链数值矛盾**（最高优先）：无卡对 Boss 唯一伤害源=道具导弹，Boss 战生成节奏（8s×0.6×40/145）约 1 枚/48s，对 30HP 差 2 个数量级；"无卡 45-60s 击杀"与"0.1/s DPS"两个说法自相矛盾。候选：Boss 战道具生成提速/导弹权重再倾斜/新增非导弹构筑对 Boss 的通用手段。
2. **满配 DPS 突破防秒杀红线**：蜂群+屠龙者+火力全满中位 10.2s（§6.3 红线 ≥20s）；§4.9"成型火力 25-30s"与 §4.6"0.35-0.5/s DPS"亦自相矛盾。候选：Boss HP 上调/火力卡对 Boss 收益递减/接受满配爽点并改红线文案。
3. **随机/非火力构筑通关率 0%**：Boss 成为"无导弹不通关"的硬门槛，与 §4.9"无卡能赢"设计意图冲突；真机盲测前需先定数值方向。

### 经验
- 步骤C 再次验证"专项断言先行"的价值：三处 bug（hitTest 口径/同帧面板踩踏/遍历快照）均在无 UI 的断言与模拟器层暴露，未流入真机。
- 模拟器"站撸下限口径"与真人有系统性偏差：脚本不躲弹幕、不追道具，胜率类指标偏下限；火力注入口径（合理等级）比"优先选卡"更能稳定回答"成型构筑会怎样"。
