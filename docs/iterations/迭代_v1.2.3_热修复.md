# 迭代_v1.2.3_热修复

> 简版记录。类型：线上热修复（hotfix）。日期：2026-09-12。

## 现象（P0）
真机用户反馈：**升级时技能选择弹窗不出现**——游戏继续运行，但 UPGRADING 面板永远不弹出，`pendingLevelUps` 一直挂起。

## 根因
v1.2.2 B2-①「延迟弹板」引入的 `_isUpgradeSafeZone()` 判定恒不成立：

```js
// v1.2.2（错误）：要求小鸟越过【所有】管道的右边缘+边距
if (pipe.x + pipe.width + margin > birdLeft) return false
```

- 小鸟 x 坐标固定（`screenW * BIRD.X_RATIO`），管道从屏幕右侧持续生成（`new Pipe(screenW + 10, ...)`）并向左移动；
- 正常游玩中屏幕上**永远存在小鸟前方尚未到达的管道**，其 `pipe.x + width + margin > birdLeft` 恒为真 → 安全区恒 false；
- 唯一安全窗口是开局第一根管道生成前，升级几乎必然错过 → 弹窗卡死。

本质是判定范围错误：设计意图是"不在管道中间弹板"，实现却成了"越过所有管道（含前方远处的）才弹板"。

## 修法
1. **安全区判定修正**（Game.js `_isUpgradeSafeZone`）：只判定与小鸟横向区间相交（±SAFE_MARGIN_PX）的管道——即"正在穿越的管道"。前方远处管道不参与判定（弹出后游戏冻结 + 关板 45 帧无敌已覆盖该风险）。
2. **保底超时**（B2-③）：新增 `UPGRADE.MAX_DELAY_FRAMES = 90`（1.5s）与 `Game._upgradeDelayFrames` 计时；安全区持续不满足超 90 帧则强制弹板并 `Logger.warn`，**保证任何情况下弹窗必出现**。计时在弹板/选卡/无 pending/start/backToReady/restart 全路径清零，不泄漏（凤凰复活期间 update 早退、计时自然暂停，复活后继续）。
3. **移除 N6 跳过按钮**（用户要求）：`_skipUpgrade()`、`_skipBtnBounds`、UPGRADING 触摸跳过分支、面板按钮绘制、`UPGRADE.SKIP_EXP` 及注释全部清理。
4. **保留不变**：B2-② 关板 45 帧无敌 + 垂直速度清零。

## 验证
- 三模拟器回归：`test_gameplay_sim` / `test_builds_sim` / `test_weather_sim` 全部跑通。
- 专项断言（临时脚本，用后已删）21 项全过：
  - 安全区单元逻辑 6 例（无管道/前方远处/已越过/正在穿越/前方边距内/刚出间隙未及边距）；
  - 正常路径 pendingLevelUps>0 后 **1 帧**弹板；
  - 最坏路径（安全区恒 false）**恰好 90 帧**保底强制弹板（要求 200 帧内必达）；
  - 关板 45 帧无敌 + 速度清零保留；backToReady/restart 标志位重置；N6 移除 3 例。
- 50 局一致性（模拟器驱动）：触发升级 801 次 = 完成选卡 801 次，50/50 局有升级，选卡 while 循环最大迭代 2（guard=20 未触顶，无死循环），正常游玩保底强制弹板 0 次（安全区判定本身已足够可靠，超时仅兜底）。
