## 2. 步骤一：拟人化难度测量（test_human_sim.js，D22）

既有 test_gameplay_sim 的脚本玩家是"完美追线机器人"，严重低估真人难度。新建 test/test_human_sim.js（不改既有文件，复制其 mock 模式），真人玩家模型（"中等水平真人"校准假设，参数在文件头）：

| 模型要素 | 参数 | 校准依据 |
|---|---|---|
| 反应延迟 | 拍翅决策滞后 8-14 帧随机（133-233ms） | 简单视觉反应时间典型值 150-250ms，熟练玩家取偏快端 |
| 跟踪误差 | 目标高度 ±15-30px（每根新管道重抽） | 间隙 180px 的 10-15% 瞄准误差 |
| 过冲修正 | 拍翅后 6-12px 过冲量，每帧衰减 0.4px | 拍翅后惯性上冲，玩家刻意"等多落一点"再补拍 |
| 偶发愣神 | 每 10s 约 4% 概率，15-25 帧不操作 | 看消息/眨眼/手指移位的操作空窗 |
| 前置预判 | 按反应窗口均值（11 帧）外推落点提前决策 | **必要校准项**：纯滞后模型振幅 ~110px 必擦管道，实测中位仅 7.3s，不符合任何真人水平；真人会预估"反应延迟内还要掉多少" |

**调参前基线（100 局/seed=20260151）**：

| 指标 | 拟人基线 | 机器人基线（gameplay_sim 同版本） |
|---|---|---|
| 中位生存 | **19.6s** | 69.6s |
| 均值生存 | 20.4s | 68.1s |
| 前 30s 死亡率 | **80%** | 2% |
| 前 60s 死亡率 | **99%** | 30%（0-60s 段内死亡占比） |
| 常见死亡窗口 | 10-20s(31%)/20-30s(27%)/0-10s(22%) | — |
| 死因 | 撞管道 95%/撞地面 5% | 撞管道 94%/冰雹 6% |

真机反馈"前期暴毙"在拟人模型下清晰复现；机器人基线对此完全不可见（差距 3.5 倍）。

## 3. 步骤二：前置依赖卡过滤（D23）

- GameConfig.ABILITY 新增 **PREREQUISITES 依赖表**（单一事实源）：`iron_feather→echo_wing`、`time_crystal→time_warp`——沿用 v1.4.0 灰显逻辑登记的全部条目，无遗漏（全库 grep 确认仅这两张依赖卡）。
- AbilityRegistry **四个抽卡入口统一口径**（rollChoices/rollRarePlus/rollEpic/rollBossRewardChoices）：前置未持有时依赖卡直接不进候选池。
- Game._getCardGreyReason 改读同一配置表；**灰显逻辑保留为兜底**（防未来旁路抽卡池的直发面板路径），正常路径不再触达；先知（oracle）协同标注不受影响。
- **专项断言 11/11 过**（临时文件，用后删除）：前置未持有 200 次 roll 四入口 0 次出现依赖卡、面板恒 3 张无残版；持前置后正常出现（铁羽 8 次/时之晶 19 次，200 次 roll）；仅持前置之一时另一依赖卡仍过滤；先知 synergy 标注不变。

## 4. 步骤三：难度调优迭代记录（拟人 100 局闭环，D24）

| 轮次 | 改动 | 拟人中位 | 拟人前30s死亡 | 机器人中位 | 结论 |
|---|---|---|---|---|---|

| R3 | +c) 初始 HP 2→3 | 46.1s | 18% | 82.5s | 拟人双达标，但机器人破 builds_v140 ⑥ 参考带上限 78s（新增 FAIL）→ **否决放弃**（HP 大改不成立，护盾流零改动） |
| R4 | ramp2 加强（60s+ 对冲后期泛化） | 46.1s | 18% | 86.6s | 无效（±0.05px/f 量级太小且混沌反升）→ 还原 |

## 7. 遗留问题
1. **拟人模型未覆盖的真人行为**：不看天气预报/不用主动卡时机/道具取舍失误等，真人实际难度仍可能高于拟人模型；建议真机复测校准（若仍偏难，备选杠杆：EARLY_EASE 幅度再加大、MIN_GAP 120→130）。
2. **混沌敏感性**（D24 登记）：50 局确定性 LCG 下机器人中位对任何 RNG 扰动 ±5s 漂移，builds_v140 ⑥ 带内余量仅 4.6s——后续版本任何改动都需随测六模拟器。
3. **④血契流子项翻转**：离散度 P75/P25 2.58→1.94 由 PASS 转 FAIL（④整体本就 FAIL 属允许残差；血契中位 18.3→45.1s 实质改善，破产后保命窗口变长压扁了离散度）。
4. **builds_v140 ①胡/不胡差距 1.3 倍**（基线 1.7，目标 4-7）：减压普遍抬升地板，差距反向缩小——与"让没胡局也能玩"存在内在张力，留 v1.6.0 评审（候选：成型流派后期专属加压）。
5. **③没胡陷阱流 67.5s** 距 68s 线差 0.5s（基线 50.2s 大幅改善，仍为允许残差）。
