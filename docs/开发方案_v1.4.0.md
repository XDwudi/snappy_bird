## 1. 设计目标与原则

### 1.1 对审计问题的逐条回应

| 审计问题（出处） | 设计回应 | 落点 |
|---|---|---|
| 机制型卡占比太低，28 卡中绝大多数是线性数值（审计 §二） | 新增 14 张卡中机制型 11 张（79%），纯数值卡 0 张，条件数值卡 3 张 | §2 |
| common 池只有 3 张且无梦想卡，"抽卡失望感"主因（N6 遗留） | common 补 3 张机制卡：求生本能/锐利目光/拾荒者，每张都是一个流派的低成本入口 | §2.1 |
| 所有能力线性成长、无满级质变（审计 §二） | 超载神盾 Lv3 质变（溢出护盾转 HP）；另给 3 张旧卡设计满级质变补丁（§2.4） | §2.2-R2、§2.4 |
| 护盾流偏强（满时长局 58%）、经验流前强后痿、位移流不成立（审计 §四） | 不削旧卡，用新卡抬其他流派天花板：经验流补"复利"，位移流整体退役由"反杀碰瓷流"替代操作位 | §3 |
| 后期 3 分钟后压力不足，终局是挂机期（N5 已修一半，仍缺高潮） | Boss 战在 180s 制造强制高潮；精英怪填充 45s~180s 的中场 | §4、§5.1 |
| 怪物/导弹系统只做了"威胁"，没做"构筑资源"（v1.3.0 遗留） | 6 张新卡与怪物/导弹联动，把怪物从纯威胁变成可经营的经济来源 | §2.2/§2.3 |
| 胡/不胡差距 5.5 倍（健康区间 4-7 倍），新卡不得拉大 | 平衡目标写进验收：胡/不胡中位生存差维持 4-7 倍 | §6 |

### 1.2 设计原则（含必须避开的坑）

1. **手感神圣不可侵犯**。顺风/轻羽的教训（实测 -35s，N3）：任何新卡不得修改重力、上升力、拍翅响应曲线。本方案 14 张新卡**零手感改动**，全部作用在判定、资源、规则层。
2. **禁止指数回路**。连击之心 Lv3 永动无敌的教训（N1）：凡"触发 A 奖励 B，B 又加速触发 A"的结构必须加上限（次数/每局/CD），数值表中逐卡注明刹车。
3. **禁止触发遮蔽**。时间扭曲压着瞬移的教训（N4）：新卡凡涉及"即将受击时触发"的，必须在同一张**受击决策优先级表**里登记（§2.5），写代码前先对齐顺序。
4. **单手操作约束**。全部新机制零新增输入位；Boss 战所有躲避动作都由"拍翅/二段跳"完成。
5. **实现成本对齐审计 A2/A3**。被动数值卡 ≤2 处改动；主动卡 ≤5 处；Boss 战前置条件是 Game.js 拆出 SpawnSystem/渲染层，否则不做。
6. **无素材依赖**。全部视觉用 Canvas 几何体 + 粒子，包体增量预算 ≤50KB 代码。

## 4. Boss 战设计：雷羽巨鹰

### 4.1 定位

首个 Boss「**雷羽巨鹰**」（Storm Roc）：单局的中期高潮事件，填补"3 分钟后挂机期"（审计 §七），同时是导弹/怪物系统的价值放大器。视觉：翼展 ~140px 的几何体巨鸟（复用 Bird 绘制语言放大 + 雷云色描边 + 羽翼粒子），零素材。

### 4.2 触发机制

| 参数 | 数值 | 设计依据 |
|---|---|---|
| 触发条件 | 存活 ≥180s **且** 等级 ≥Lv10，两者同时满足时触发 | 审计"成长集中前 2 分钟，第 3 分钟起无聊"：180s 正是体验低谷起点；Lv10 保证玩家有基础构筑进场 |
| 迟到兜底 | 180s 时未达 Lv10，则达 Lv10 的下一波天气冷却结束后触发 | 避免与天气叠加进场（压力不可控） |
| 每局次数 | 胜利：1 次；战败：240s 后可再战 1 次（见 4.7） | 单局 3-10 分钟目标下，Boss 是"一场"不是"无限刷" |
| 出场演出 | 屏幕四角暗角收拢（30 帧）→ 顶部浮动文字"雷云聚集……"（1s）→ Boss 从右侧幕外飞入至 x=70% 处（60 帧）→ 血条展开 | 无音效现状下全靠视觉；暗角复用凤凰动画的遮罩技术，成本极低 |

### 4.3 基础数值

| 参数 | 数值 | 设计依据 |
|---|---|---|
| HP | **30** | 无导弹卡玩家靠道具导弹（Boss 战权重上调后期望 ~6 发/分钟）+ 铁喙反杀小怪（不计 Boss 伤）≈ 45-60s 击杀；火力流（火力覆盖+挂架 ~8-10 发/分钟）≈ 25-30s。落在"一场硬仗但不折磨"区间 |
| 体型 | 140×90px，碰撞箱 0.8 系数 | 是浮游怪的 4 倍面积，"巨大感"优先于躲避难度 |
| 移动 | 基准 x=屏幕 70%，y 做振幅 120px、周期 4s 正弦 | 复用蝙蝠正弦参数放大；保持在右侧，不越过屏幕中线（给玩家留足躲避空间） |
| 接触伤害 | 1（走统一受击链） | 与所有 Obstacle 一致 |
| 碰撞反杀免疫 | 铁喙对 Boss 无效（受击接口内 `isBoss` 分支） | 否则碰瓷流 1 秒 1 伤变最优解，火力流作废 |

### 4.4 战斗期间的核心玩法（明确结论）

**结论：Boss 战期间管道停止生成、普通怪物停止生成、天气计时暂停，屏幕上只剩 Boss + 弹幕 + 召唤小怪 + 道具。**

| 系统 | Boss 战期间行为 | 设计依据 |
|---|---|---|
| 管道 | 停止生成，存量管道滚出后不再补充（SPAWN 距离制加 `bossActive` 开关，v1.3.0 距离制改造让这个开关是 1 行成本） | 管道间隙注意力与弹幕躲避注意力**互斥**，单手玩家无法兼顾；但拍翅飞行本身保留——"飞"仍是核心，只是目标从穿缝变成躲弹 |
| 普通怪物 | 停止生成（Boss 召唤物除外，见 4.5） | 同屏威胁源 ≤3（Boss+弹幕+召唤物）的可读性上限 |
| 天气 | 计时暂停，正在生效的天气以当前强度冻结（不再加重） | 风暴之子/御风者玩家不被剥夺构筑（天气利用流补偿）；也不会雨+弹幕双重重力惩罚 |
| 道具 | 照常生成，且导弹权重从 20/125 上调至 40/145 | 无火力卡玩家的保底输出手段，同时让火力流更爽 |
| 升级面板 | 战斗中升级照常弹板（UPGRADING 状态暂停一切，现有机制天然安全） | 不打断成长节奏 |

### 4.5 阶段与攻击模式

全部攻击用现有组件拼装：弹幕 = Hailstone 改为水平飞行（新实体 Feather ≈80 行）；召唤 = Monster 工厂；冲刺 = Obstacle 线性位移。

**P1（HP 100%→50%）「巡游威慑」**

| 攻击 | 参数 | 设计依据 |
|---|---|---|
| 羽刃弹幕 | 每 4s 一轮，扇形 3 发（间隔角 0.35rad），速度 4.5px/f（≈当前世界滚动速度），半径 5px，伤害 1 | 弹速对齐世界速度：玩家已有"以滚动速度预判"的肌肉记忆；3 发扇形在中线留出 2 条稳定通路 |
| 移动 | 正弦巡游（4.3） | P1 是教学段：让玩家学会"弹幕有预警线→找通路" |

**P2（HP <50%）「风暴暴怒」**：入场瞬间 Boss 周身闪电粒子爆闪 30 帧 + 血条变色（金→红）。

| 攻击 | 参数 | 设计依据 |
|---|---|---|
| 羽刃弹幕 | 每 2.5s 一轮，扇形 5 发，速度 5.5px/f | 压力提升但不翻倍：单手操作天花板下，5 发/2.5s 是模拟器可验证的上限候选值 |
| 召唤 | P2 入场及之后每 15s 召唤 2 只蝙蝠（从 Boss 位置飞出，HP=1，参数同普通蝙蝠） | 复用 Monster；召唤物是火力流的"连锁弹药"，也是拾荒者的掉落来源——威胁即资源 |

**预警规范**：所有攻击前摇 ≥0.5s 且有独立视觉语言（弹幕=炮口亮点，冲锋=泛白+警示带）。单手游戏没有"看不过来"的借口，只有"预警不够"的设计失误。

### 4.7 奖励与失败惩罚（明确结论）

**打赢**（三样全给，这是"局内最高峰"，不能小气）：

| 奖励 | 数值 | 设计依据 |
|---|---|---|
| 稀有卡自选面板 | 立即弹出特殊 3 选 1：1 张史诗 + 2 张珍贵（从当前卡池抽取，满级卡已自动移出） | 对标 VS 的宝箱时刻；把"胡"的峰值从抽卡运气里拿出一部分变成"打赢的确定性回报" |
| 经验 | 直接 +2 级所需经验（按当前等级曲线 18+12×Lv 计算 ×2） | 战斗中断成长，双倍补偿 |
| 分数 | +50 分 + 战斗期间击杀/弹幕擦边照算 | 结算界面新增"Boss 讨伐"徽章行 |

**打输**：采用**方案 A：扣 1 HP（走受击链，可被护盾/羽盾减免），Boss 长鸣离场，游戏继续**；240s 后 Boss 以满血回归一次，再战失败则不再出现。
（方案 B"直接结束本局"列入 §9 待评审。A 的理由：单局 3-10 分钟目标下，180s 的局直接结束等于否定玩家前 3 分钟成长；且 HP=2 开局玩家败北≈死，惩罚弹性由护盾/临时 HP 自然调节。血契流 HP=1 玩家战败=死，这是该流派自选的极限属性，属于"知道风险仍上车"。）

### 4.8 HUD 与视觉

| 元素 | 方案 |
|---|---|

## 5. 其他新机制提案（3 个）

### 5.1 精英怪（成本：小）

| 项 | 内容 |
|---|---|
| 规则 | 45s 保护期后，每 60s 有 25% 概率把下一只生成的怪物升级为精英：金色描边+体型 ×1.3，HP ×3（蝙蝠 1→3，浮游 2→6），移动参数不变 |
| 击杀奖励 | 必掉 1 个随机道具（导弹权重 ×2）+ 经验 ×5（10→50） |
| 为什么好玩 | 45s~180s 是 Boss 前的中场，普通怪物 2 只同屏不构成"事件"；精英给中场一个可识别的"高价值目标"，火力流有靶子、碰瓷流有跳板、其他流派有额外道具 |
| 实现成本 | **小**：Monster 加 `elite` flag × 数值系数 + Game 生成处 roll；≤30 行。建议随 v1.5.0 与 Boss 同车上（共用"怪物价值化"心智） |

### 5.2 诅咒卡（成本：中）

| 项 | 内容 |
|---|---|
| 规则 | 升级面板 15% 概率额外出现第 4 张"诅咒卡"（暗红边框，不占 3 选 1 名额）：效果 = 永久 debuff + 立即获得大额补偿。首发 3 张：①重力 +8% → 补偿直升 1 级；②管道间隙 -12px → 补偿指定稀有卡 1 张（随机 3 选 1）；③怪物 HP +1 → 补偿临时 HP +1（本局） |
| 数值依据 | debuff 幅度全部**低于**对应正向卡的单级幅度（间隙 -12 < 缩小射线 +20），保证"补偿 > 代价"在数学上成立，赌的是构筑契合度 |
| 为什么好玩 | 把"3 选 1 之外"加一个主动博弈位；与血契共享"拥抱风险"语言，丰富胡法多样性 |
| 反直觉风险 | 诅咒①动重力——**违反手感原则**，列入待评审（§9-D3）；若评审否决，替换为"受击无敌 -0.3s" |
| 实现成本 | **中**：抽卡面板加第 4 卡位（UI 已有 6 卡布局先例 v1.2.1）+ 3 个 debuff 挂载点 |

### 5.3 每日种子挑战（成本：中）

| 项 | 内容 |
|---|---|
| 规则 | 每天 0 点生成固定种子（`YYYYMMDD` 哈希）：该种子下抽卡序列、天气序列、道具序列全固定（模拟器 LCG 已验证可行性，test_builds_sim 同款机制），主界面"每日挑战"入口，当日最佳成绩本地存档 |
| 为什么好玩 | 同种子=公平竞技，是社交分享（v1.2.0 §17 上线必需项）的天然载体："今天你打到第几波弹幕？"；也给硬核玩家一个可反复研究的确定性谜题 |
| 依赖 | Storage 扩展（当前仅存最高分，金币/皮肤 API 悬空——本机制正好推动存档层补齐）；分享能力等 v1.5.0 后社交版本 |
| 实现成本 | **中**：LCG 注入主循环（替换 Math.random 的 4 个调用点）+ 存档字段 + 入口 UI |

## 6. 数值平衡框架

### 6.1 抽卡池权重变化（按 GameConfig.RARITY 基础权重计算）

| 稀有度 | 现状（28 卡） | 扩展后（42 卡） | 占比变化 |
|---|---|---|---|
| common（权重 10/张） | 3 张 → 30 | 6 张 → 60 | 22.7% → **29.6%** |
| uncommon（6/张） | 11 张 → 66 | 15 张 → 90 | 50.0% → 44.4% |
| rare（3/张） | 10 张 → 30 | 14 张 → 42 | 22.7% → 20.7% |
| epic（1.5/张） | 4 张 → 6 | 7 张 → 10.5 | 4.5% → **5.2%** |
| 总权重 | 132 | 202.5 | — |

解读：common 占比上升是**有意设计**（N6：让每次开局更早摸到支点卡）；史诗占比 4.5%→5.2% 微升但单卡被稀释（每张史诗出现率 1.14%→0.74%），"胡特定史诗"不会变容易。未拥有卡 ×1.3 权重与 N9 软保底（5 次无稀有保底 1 张）机制不变，继续兜底。

### 6.2 对胡/不胡差距的预期影响

- 新 common 支点卡（求生本能/锐利目光/拾荒者）抬**下限**：预期"没胡"中位生存 55s → 65-75s。
- 超载神盾/风暴驯化/导弹风暴抬**上限**：预期天胡中位 300s 维持打满，但满时长率不应回升到 v1.2.1 前的 80%。
- **净效应预测：胡/不胡中位生存差从 5.5 倍收敛至 4-5 倍，仍在 4-7 倍健康区间。**

### 6.3 可验证指标（test_builds_sim / test_gameplay_sim 验收口径）

| 指标 | 当前基线 | v1.4.0 目标 | 验证方式 |
|---|---|---|---|
| 胡/不胡中位生存差 | 5.5 倍 | **4-7 倍区间内，且不高于 5.5** | test_builds_sim 新增 3 个 build（猎杀火力/反杀碰瓷/血契狂战）后全量 8 流派 ×50 局 |
| 铁壁护盾流满时长率 | 58%（300s 上限） | ≤55% | 同上 |
| 没胡陷阱流中位生存 | 55.0s | ≥65s | 同上（没胡 build 加入 common 新卡随机池） |
| 随机基线中位生存 | 63.8s（test_gameplay_sim v1.3.0） | 60-75s（新卡稀释池后不得显著偏离） | test_gameplay_sim 50 局回归 |
| 血契狂战流（新 build） | — | 中位 80-140s，P75/P25 比值 >2（方差大是特性） | test_builds_sim 专项断言 |
| 火力流击杀怪物贡献 | — | 火力流 build 的怪物击杀数 ≥ 其他流派均值 ×3 | GameLogger 新增 kill 统计字段 |
