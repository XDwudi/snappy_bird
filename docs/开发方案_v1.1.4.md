## 1. 项目概述

### 1.1 一句话定位

> 一款融合 Flappy Bird 操控手感与 Vampire Survivors 式 roguelike 成长的小游戏生存游戏 —— 单指操作，越玩越强，每局都不一样。

### 1.2 核心体验

| 维度 | 设计目标 |
|------|----------|
| 操作 | 单指点击，0学习成本，3秒上手 |
| 单局时长 | 3~10分钟，适配碎片化场景 |
| 成长感 | 每局内获得15~25次升级选择，构筑流派 |
| 重玩性 | 能力随机组合 + 道具随机掉落 + 稀有度概率 + 难度递增 |
| 视觉 | 像素复古风格，Canvas 2D 纯渲染 |

### 1.3 技术栈

- 微信小游戏模式（非小程序）
- 纯 Canvas 2D 渲染，无游戏引擎
- 包体最小化，对象池 + 离屏Canvas优化
- 无 WXML/WXSS，所有UI通过Canvas绘制

## 3. v1.1.0 核心系统扩展

### 3.1 HP血条系统
- 初始2HP，碰撞扣1HP
- 受击无敌60帧（体魄能力可延长）
- 碰撞优先级链：无敌 > 时间扭曲 > 弹力护甲 > 护盾 > 扣血 > 凤凰 > 死亡

### 3.2 道具系统
- 4种道具类型：经验包(40%) / 血包(20%) / 护盾包(25%) / 速度包(15%)
- 通过管道时25%概率生成
- 经验包：15~30随机经验
- 血包：恢复1HP（满血转5分）
- 护盾包：5秒护盾
- 速度包：3秒全局减速50%

### 3.3 新增7个能力
- 活力之心（被动）：最大HP+1/级
- 体魄（被动）：受击无敌+0.5s/级
- 自愈（主动）：定期恢复HP
- 弹力护甲（主动）：碰撞弹开免伤
- 二段跳（主动）：快速双击额外上升
- 经验共鸣（特殊）：经验球概率双倍 → [v1.1.4] 改为所有经验概率双倍
- 狂暴（特殊）：HP=1时全属性提升

### 3.4 OOP架构重构
- Obstacle基类 → Pipe继承（模板方法模式）
- Collectible基类 → Orb/Item继承
- 安全区适配：safeArea.top/bottom 直接用作Y坐标

## 5. v1.1.2 系统日志与平衡性修复

### 5.1 GameLogger模块
- 单例模式，四级日志（DEBUG/INFO/WARN/ERROR）
- 环形缓冲800条，支持按Tag/级别过滤
- exportText()导出全量日志用于排查

### 5.2 平衡性修复

#### 弹力护甲不死Bug
- **问题**：无限使用+传送到安全位置=无法死亡
- **修复**：改为有限充能（Lv1=2/Lv2=3/Lv3=4次），弹开不传送，CD增至30s
- 天花板向下弹，地面/管道向上弹

#### 连击之心永久无敌Bug
- **问题**：阈值公式`max(1,5-2*lv)`在Lv2时阈值=1，每管触发=永久无敌
- **修复**：阈值改为`max(2,5-lv)`，无敌持续3s（180帧）

#### 狂暴缓存Bug
- **问题**：takeDamage/healHP后未调invalidateStats()，狂暴属性延迟生效
- **修复**：两个方法均添加invalidateStats()调用

#### 瞬移无敌帧缺失
- **问题**：瞬移后仅invincibleBlink视觉闪烁，无实际无敌帧
- **修复**：添加invincibleFrames=30（0.5s）

## 7. v1.1.4 经验统一化与视觉增强

### 7.1 经验系统统一化

#### 变更说明
- **通过管道经验**：5 → 10
- **删除经验球经验**：通过管道不再有70%概率额外获得经验球经验（+10EXP）
- **经验球保留**：ORB_EXP等配置保留，后续版本可重新启用
- **经验共鸣改为全经验生效**：不再局限于经验球拾取，所有经验来源（通过管道/擦边/经验包/经验球）均有概率触发双倍

#### 统一经验获取方法 `_gainExp()`
```
_gainExp(baseExp, source, stats) {
  1. 检查经验共鸣 → 概率双倍
  2. 应用expMultiplier倍率
  3. 添加到expSystem
  4. 生成浮动文字（带堆叠偏移）
  5. 记录GameLogger日志
}
```

所有经验来源统一调用此方法：
- `_onPipePass()` → `_gainExp(10, 'pipe_pass', stats)`
- `_checkNearMiss()` → `_gainExp(15, 'near_miss', stats)`
- `_collectItem(exp_pack)` → `_gainExp(15~30, 'exp_pack', stats)`
- `_collectOrb()` → `_gainExp(10, 'orb', stats)`

#### 经验共鸣配置更新
- desc: '拾取经验球概率双倍' → '获得经验时概率双倍'
- effectText: `${20*lv}%概率经验球双倍` → `${20*lv}%概率获得双倍经验`
- 概率不变：Lv1=20% / Lv2=40% / Lv3=60%

### 7.2 浮动文字堆叠渐隐

#### 问题
- 短时间获得多组经验时（通过管道+擦边+经验包），文字提示叠在一起不可读

#### 解决方案
- **堆叠偏移**：新增浮动文字时，检查附近已有文字数量，向上偏移`count × 18px`
- **速度衰减**：vy从-1.5逐渐向0衰减，末段减速更自然
- **渐隐优化**：前60%生命周期保持完全不透明，后40%线性渐隐

```
_addFloatingText(x, y, text, color, life) {
  stackCount = 附近文字数
  yOffset = stackCount * 18
  push({ x, y - yOffset, text, color, life, vy: -1.5, vyDecay: 0.02 })
}
```

### 7.3 擦边特效增强

#### 问题
- 原有擦边特效仅一个扩散光环，不够明显

#### 增强方案
- **多环扩散**：3层光环，不同初始半径/最大半径/线宽/生命周期
  - 大环：10→55px, 30帧, 线宽3
  - 中环：8→40px, 24帧, 线宽2
  - 小环：5→25px, 18帧, 线宽4
- **粒子爆发**：8个粒子向外散射，带重力+尾迹
  - 初始速度2.5~5.0，重力0.1/frame
  - 尾迹粒子+核心粒子双层渲染
- **中心闪光**：12帧白色+黄色闪光，最亮最短暂
- **浮动文字**：向上偏移至y-45，与经验文字不冲突

### 7.4 道具图标视觉区分

#### 问题
- 原有道具全部使用emoji图标，不同平台渲染不一致，且不够直观

#### 解决方案
- 废弃emoji图标，改为Canvas路径绘制独特形状
- 每种道具有一眼可识别的视觉特征：

| 道具类型 | 背景色 | 图标形状 | 视觉含义 |
|----------|--------|----------|----------|
| 血包 (health_pack) | 红色 | 白色医疗十字 | 治疗/恢复 |
| 经验包 (exp_pack) | 紫色 | 黄色五角星 | 经验/成长 |
| 护盾包 (shield_pack) | 蓝色 | 白色盾牌+十字 | 防护/抵挡 |
| 速度包 (speed_pack) | 青色 | 黄色闪电 | 速度/减速 |

- 绘制方法：`_drawHealthIcon()` / `_drawExpIcon()` / `_drawShieldIcon()` / `_drawSpeedIcon()`
- 保留外层光晕+主体圆形+描边的整体结构

## 10. 架构设计

### 10.1 入口流程
```
game.js
  ├── wx.createCanvas() → 获取主画布
  ├── ctx.scale(dpr) → 高分屏适配
  ├── wx.getSystemInfoSync().safeArea → 安全区
  ├── new Game(canvas, ctx, screenW, screenH, safeArea)
  ├── wx.onTouchStart → game.handleTouch(x, y)
  └── game.loop() → requestAnimationFrame 循环
```

### 10.2 状态机
```
READY → (点击) → PLAYING → (经验满) → UPGRADING → (选能力) → PLAYING
                                        ↓
                          (死亡) → GAME_OVER → (重新开始) → PLAYING
                                   (返回首页) → READY
```

### 10.3 OOP继承体系
```
Obstacle (基类)
  └── Pipe (管道)

Collectible (基类)
  ├── Orb (经验球, 保留)
  └── Item (道具)
       ├── exp_pack (经验包)
       ├── health_pack (血包)
       ├── shield_pack (护盾包)
       └── speed_pack (速度包)
```

### 10.4 系统模块
```
Game (主控制器)
  ├── ExpSystem (经验与升级)
  ├── AbilitySystem (能力属性计算 + HP/护盾/冷却)
  │     └── AbilityRegistry (能力注册表 + 稀有度加权抽取)
  └── GameLogger (系统日志, 单例)
```

### 10.5 能力属性注入流程
```
AbilitySystem.getStats() → 计算属性对象 → Game._applyAbilityStatsToBird()
  ├── gravity × gravityMultiplier
  ├── flapForce × flapForceMultiplier
  ├── collisionScale → bird.updateCollisionBox()
  └── expMultiplier / scoreMultiplier / scrollSpeedMultiplier ...
```

### 10.6 [v1.1.4] 统一经验获取流程
```
任意经验来源
  └── Game._gainExp(baseExp, source, stats)
        ├── checkExpResonance() → 概率双倍
        ├── expSystem.addExp(exp, expMultiplier)
        ├── _addFloatingText() → 堆叠不重叠 + 渐隐
        ├── Logger.info() → 经验日志
        └── onExpChange() → 更新HUD经验条
```

## 11. 技术栈与工程

### 11.1 Git版本管理
- 远程仓库：https://github.com/XDwudi/snappy_bird.git
- 分支策略：main为主分支，每次迭代提交一次
- commit规范：`类型: 描述`（feat/fix/docs/refactor）

### 11.2 包体优化
- 纯Canvas渲染，无引擎依赖
- 无第三方库
- 对象池模式减少GC
