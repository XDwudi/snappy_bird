### 经验
- 步骤C 再次验证"专项断言先行"的价值：三处 bug（hitTest 口径/同帧面板踩踏/遍历快照）均在无 UI 的断言与模拟器层暴露，未流入真机。
- 模拟器"站撸下限口径"与真人有系统性偏差：脚本不躲弹幕、不追道具，胜率类指标偏下限；火力注入口径（合理等级）比"优先选卡"更能稳定回答"成型构筑会怎样"。
- 火力 build 击杀时长对"每发伤害"高度敏感（dmg 5→3 时 TTK 24s→40s+，胜率 33%→3%）：Boss 战本质是 DPS 竞速，后续调参应同时看 TTK 与胜率两条曲线。
- D21 数值闭环补充：①调参前先修脚本玩家建模——原 pilot 固定悬停 45%H 与弹幕相位锁定="站枪口"，修正为随机悬停 0.25-0.65H+反应式避让后，实测才反映真实难度；②期间暴露实战 bug④（Missile._targetPoint 对 Boss 走管道分支瞄 ±42px，超出 ±36px 命中窗=系统性脱靶）并已修复；③三件套各司其职：保底供给解决"无卡零输出"、伤害系数 ×4 只乘基础伤害（hunter/slayer 保持 flat，避免等比加速火力流）、受击门 45f 抬满配 TTK 而不拖死无卡——提 HP 方案会等比拖长所有 build，被否决。
