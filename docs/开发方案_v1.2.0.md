## 1. 项目概述

### 1.1 一句话定位

> 一款融合 Flappy Bird 操控手感与 Vampire Survivors 式 roguelike 成长的小游戏生存游戏 —— 单指操作，越玩越强，每局都不一样。

### 1.2 核心体验

| 维度 | 设计目标 |
|------|----------|
| 操作 | 单指点击，0学习成本，3秒上手 |
| 单局时长 | 3~10分钟，适配碎片化场景 |
| 成长感 | 每局内获得15~25次升级选择，构筑流派 |
| 重玩性 | 能力随机组合 + 道具随机掉落 + 稀有度概率 + 难度递增 + **环境随机变化** |
| 视觉 | 像素复古风格，Canvas 2D 纯渲染 |
| 动态感 | **环境系统带来随机挑战，动画特效增强反馈**（v1.2.0） |

### 1.3 核心循环

```
点击飞行 → 躲避障碍 → 收集经验/道具 → 升级选能力 → 变强生存 → 应对环境变化 → 死亡重开
    ↑                                                                        |
    └────────────────────────────────────────────────────────────────────────┘
```

### 1.4 技术栈

- 微信小游戏模式（非小程序）
- 纯 Canvas 2D 渲染，无游戏引擎
- 包体最小化，对象池 + 离屏Canvas优化
- 无 WXML/WXSS，所有UI通过Canvas绘制

### 1.5 v1.2.0 版本要点

v1.2.0 是第一个大版本更新，核心新增三大系统：

| 系统 | 一句话描述 |
|------|-----------|
| 环境系统 | 游戏中随机触发风/雨/冰雹环境效果，增加动态挑战 |
| 新能力（6个） | 6个环境相关能力，与环境系统形成策略闭环 |
| 动画特效系统 | 三层特效架构，凤凰复活动画，现有能力视觉增强 |

## 3. 核心玩法设计

### 3.1 基础飞行机制

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 重力加速度 | 0.45 px/frame² | 每帧持续下落加速 |
| 点击上升力 | -8.0 px/frame | 单次点击施加的瞬间向上速度 |
| 最大下落速度 | 12 px/frame | 防止下落过快不可控 |
| 前进速度（世界滚动） | 3.0 px/frame | 障碍物向左移动速度，随时间增速 |
| 小鸟水平位置 | 固定在屏幕 1/3 处 | 小鸟X轴不动，世界左移产生前进感 |

> **v1.2.0备注**：环境系统（风/雨）会动态修改重力加速度和滚动速度，基础值不变，环境效果通过 `getStatModifiers()` 叠加。

### 3.2 障碍物系统

#### 3.2.1 OOP架构（v1.1.0）

```
Obstacle (基类)
  ├── Pipe (标准管道) — 当前实现
  ├── MovingPipe (移动管道) — 预留接口
  └── Spike (尖刺障碍) — 预留接口
```

基类定义统一接口：
- `update(speed)` — 更新位置（含v1.1.5缩小射线动画）
- `checkCollision(bird)` — 碰撞检测
- `render(ctx)` — 渲染
- `passed` — 是否已被通过（得分标记）
- `nearMissTriggered` — [v1.1.5] 擦边是否已触发（防重复）
- `shrinkBonus` / `currentShrink` — [v1.1.5] 缩小射线动画参数

#### 3.2.2 基础障碍 — 管道

- 上下成对的管道，中间留有间隙供小鸟通过
- 管道从屏幕右侧生成，匀速左移至屏幕外销毁
- 每通过一对管道得 1 分 + 经验 + 道具生成

| 难度阶段 | 间隙宽度 | 管道间距 | 滚动速度 | 持续时间 |
|----------|----------|----------|----------|----------|
| 新手期 | 220px | 320px | 3.0 px/f | 0~30s |
| 普通期 | 180px | 280px | 3.5 px/f | 30s~90s |
| 挑战期 | 150px | 240px | 4.0 px/f | 90s~180s |
| 极限期 | 130px | 220px | 4.5 px/f | 180s+ |

#### 3.2.3 缩小射线动画（v1.1.5新增）

- 拥有"缩小射线"能力时，管道间隙增大 +20px/级
- 管道以基础间隙生成，两侧缓缓缩回至最终间隙（30帧动画）
- 上管道帽向上缩回，下管道帽向下缩回
- 动画期间碰撞检测同步更新，确保碰撞箱与视觉一致
- 动画在管道到达小鸟前完成（管道从屏幕右侧到小鸟约87帧）

### 3.3 碰撞判定

#### 3.3.1 碰撞箱

- **小鸟碰撞箱**：视觉尺寸的 70%，灵巧能力可进一步缩小12%/级
- **碰撞对象**：管道、地面、天花板、**冰雹实体**（v1.2.0新增）

#### 3.3.2 生命值系统（v1.1.0）

| 要素 | 设计 |
|------|------|
| 初始HP | 2 |
| 初始最大HP | 2 |
| 碰撞伤害 | 1点/次 |
| 受击无敌 | 碰撞后60帧(1s)无敌 + 体魄加成 +30帧/级 |
| 死亡条件 | HP降至0 |
| 地面碰撞 | 同样扣血（而非直接死亡） |
| 无敌期间 | 不再受碰撞伤害，可穿过障碍物 |

#### 3.3.3 碰撞优先级链（v1.2.0更新）

```
无敌帧 > 时间扭曲 > 统一护盾(弹力护盾优先) > 冰晶护体(冰雹专用) > HP扣血 > 凤凰复活 > 死亡
```

**v1.2.0 变更**：新增冰晶护体能力。当冰雹击中玩家时，若拥有冰晶护体且技能可用，冰雹转为护盾而非造成伤害。冰晶护体优先于HP扣血判定，但低于统一护盾（统一护盾先消耗）。

#### 3.3.4 擦边奖励（v1.1.5优化）

| 要素 | v1.1.0~v1.1.4 | v1.1.5 |
|------|---------------|--------|
| 触发距离 | 15px | **25px** |
| 触发时机 | 仅通过管道后检查一次 | **每帧检查（小鸟在管道x范围内时）** |
| 防重复 | 无 | **pipe.nearMissTriggered 标记** |
| 奖励 | 经验+15、分数+3 | 不变 |
| 视觉特效 | 多环扩散+8粒子+闪光（v1.1.4） | 不变 |

### 3.4 经验与升级

```
通过管道/擦边/道具 → 经验条增长 → 经验条满 → 触发升级 → 暂停游戏弹出选择面板
```

| 要素 | 值 | 说明 |
|------|-----|------|
| 基础经验 | 18 | v1.1.0: 20→18 |
| 每级增量 | +12 | v1.1.0: 15→12 |
| 通过管道经验 | +10 | v1.1.4: 5→10 |
| 擦边经验 | +15 | 不变 |
| 经验包 | +15~30 | 随机 |
| 经验共鸣 | 20%/级概率双倍 | v1.1.4: 对所有经验生效 |

### 4.3 v1.2.0 新增能力详解

#### 顺风耳（wind_reader）
- **类型**：被动
- **稀有度**：普通
- **上限**：Lv3
- **效果**：风力影响 -30%/级
- **effectText**：`风力影响 -${30*lv}%`
- **设计意图**：基础环境应对能力，普通稀有度易获取，直接削弱风效果的负面影响。Lv3时风力影响减少90%，几乎无视风。

#### 雨衣（raincoat）
- **类型**：被动
- **稀有度**：稀有
- **上限**：Lv3
- **效果**：雨水积累速度 -40%/级
- **effectText**：`雨水积累 -${40*lv}%`
- **设计意图**：减缓雨水积累速度，给玩家更多反应时间。Lv3时积累速度降低120%（即不积累），完全免疫雨效果。

#### 冰晶护体（ice_crystal）
- **类型**：主动
- **稀有度**：珍贵
- **上限**：Lv3
- **效果**：冰雹击中时获得护盾而非伤害，CD 20-3*(lv-1)s
- **effectText**：`冰雹转为护盾，CD ${20-3*(lv-1)}s`
- **CD**：Lv1=20s, Lv2=17s, Lv3=14s
- **设计意图**：将冰雹的威胁转化为护盾资源，高等级时CD短，冰雹密集期反而成为护盾补充期。碰撞优先级：统一护盾 > 冰晶护体 > HP扣血。

#### 御风者（wind_rider）
- **类型**：被动
- **稀有度**：珍贵
- **上限**：Lv3
- **效果**：风力转化为助推力 +50%/级
- **effectText**：`风力变助推 +${50*lv}%`
- **设计意图**：将风的负面影响翻转为正面助推。Lv3时风力助推+150%，风越大飞得越快，完全改变风效果的体验。

#### 气候适应（climate_adapt）
- **类型**：被动
- **稀有度**：珍贵
- **上限**：Lv3
- **效果**：环境持续时间 -15%/级
- **effectText**：`环境持续时间 -${15*lv}%`
- **设计意图**：缩短所有环境效果的持续时间，减少暴露在恶劣环境中的时间。Lv3时环境持续时间减少45%。

#### 风暴之子（storm_child）
- **类型**：特殊
- **稀有度**：史诗
- **上限**：Lv3
- **效果**：环境效果期间全属性 +20%/级
- **effectText**：`环境期间全属性 +${20*lv}%`
- **设计意图**：史诗级环境 synergy 能力，将环境威胁转化为力量爆发。与气候适应形成对立选择——缩短环境 vs 利用环境。Lv3时环境期间全属性+60%。

### 4.4 稀有度概率系统（v1.1.3，v1.2.0更新）

4级稀有度，权重随玩家等级增长：

| 稀有度 | 基础权重 | 等级增长 | 权重上限 | 能力数量 |
|--------|----------|----------|----------|----------|
| 普通 | 10 | 0 | 12 | **3**（+1: 顺风耳） |
| 稀有 | 6 | 0.2 | 10 | **12**（+2: 雨衣、二段跳已计入） |
| 珍贵 | 3 | 0.4 | 8 | **11**（+4: 冰晶护体、御风者、气候适应、护盾爆发已计入） |
| 史诗 | 1.5 | 0.6 | 6 | **4**（+1: 风暴之子） |

> **v1.2.0变更**：能力总数 22→28，新增6个环境能力分布在不同稀有度。新能力×1.3倍加成。

权重公式：`baseWeight × (1 + levelBonus × (playerLevel-1) / 10)`，钳制上限，新能力×1.3倍加成。

### 4.5 能力协同流派

| 流派 | 核心组合 | 效果 |
|------|----------|------|
| 闪避流 | 灵巧+慢速世界+缩小射线 | 碰撞箱极小+间隙极大+速度慢 |
| 经济流 | 贪婪+磁吸+双倍积分+经验共鸣 | 经验拉满，升级飞快 |
| 护盾流 | 坚韧+护盾爆发+弹力护盾 | 多层护盾+弹开免伤+持续恢复 |
| 擦边流 | 连击之心+时间扭曲+瞬移闪避 | 贴边获取奖励，自动保命 |
| 生存流 | 活力之心+自愈+体魄+弹力护盾 | 高血量+恢复+受击保护+弹开 |
| 狂暴流 | 狂暴+活力之心+凤凰之翼 | 控血1HP全属性爆发，复活保底 |
| 飞行流 | 轻羽+顺风+二段跳+灵巧 | 极致操控手感，精确穿越 |

## 7. 环境系统（v1.2.0新增）

### 7.1 设计理念

环境系统是 v1.2.0 的核心新功能，为游戏引入动态随机挑战：

- **随机性**：游戏时间越长，环境效果触发概率越高，但始终保持随机
- **多样性**：三种环境效果（风/雨/冰雹），各自独立触发、互不干扰
- **可读性**：所有环境效果都有清晰的视觉反馈，玩家能看清并做出反应
- **策略性**：6个环境相关能力让玩家可以选择适应环境或利用环境
- **节奏控制**：触发冷却+效果冷却+最大同时数量，避免环境效果过载

### 7.2 三种环境效果

#### 7.2.1 风（Wind）

**核心机制**：
- 给玩家施加一个随机方向的力（水平或垂直）
- 力量曲线变化：小→大→小（sin曲线），`force = MAX_FORCE × sin(progress × π)`
- 垂直风力影响小鸟 velocity（y轴加速/减速）
- 水平风力影响世界滚动速度（加速/减速）

**方向**：
- 水平风：向左（加速滚动）或向右（减速滚动）
- 垂直风：向上（辅助飞行）或向下（加速下坠）
- 随机选择方向，触发时固定方向

**视觉效果**：
- 屏幕上风向粒子线条（半透明白色线条沿风向流动）
- 小鸟周围风向箭头（指示当前风向和风力强度）
- 风力越强，粒子线条越多、越快

**玩家反馈**：
- 风向箭头让玩家立即知道风的方向
- 力量从小到大再变小，给玩家适应时间
- 顺风耳能力可大幅削弱风力影响
- 御风者能力可将风力翻转为助推

**数值**：
- 持续时间：15~30s（随游戏时间增长）
- 最大风力：0.15 px/frame²
- sin曲线周期 = 效果总时长

#### 7.2.2 雨（Rain）

**核心机制**：
- 使小鸟羽毛逐渐变湿，变重（下坠速度变快）
- 雨水累计量 `rainLevel`（0~100）影响重力增加比例
- `gravityBonus = (rainLevel / 100) × MAX_GRAVITY_BONUS`，最大+50%重力
- 雨水累计越多变得越重
- 雨停后雨水累计逐渐减少直到恢复正常
- 玩家每次点击（扇翅膀）雨水累计量减少5（甩水动作）

**积累机制**：
- 雨效果活跃期间，每帧 `rainLevel += ACCUMULATION_RATE × (1 - raincoat_reduction)`
- 雨效果结束后，每帧 `rainLevel -= DRY_RATE`
- 拍翅时 `rainLevel -= FLAP_REDUCTION`（不低于0）

**视觉效果**：
- 雨滴下落（半透明蓝色竖线，从屏幕顶部到底部）
- 小鸟身上蓝色积水（随rainLevel增多，颜色加深）
- 扇翅膀时小雨滴甩走特效（小鸟周围蓝色粒子飞散）

**玩家反馈**：
- 雨刚开始时rainLevel低，影响小，给玩家适应时间
- 拍翅可以主动甩水，鼓励积极操作
- 雨衣能力可大幅减缓积累速度
- 风暴之子能力在雨期间获得全属性提升

**数值**：
- 持续时间：20~40s（随游戏时间增长）
- 积累速度：0.3/帧
- 拍翅减少：5
- 干燥速度：0.5/帧
- 最大重力增加：50%

#### 7.2.3 冰雹（Hail）

**核心机制**：
- 掉落冰雹实体，触碰玩家造成1点伤害（走碰撞优先级链）
- 冰雹数量和密度：低→高→低（sin曲线）
- 冰雹从屏幕顶部生成，以5~8px/帧速度下落
- 冰雹离开屏幕底部后销毁

**生成规则**：
- 生成间隔随时间变化：`interval = SPAWN_INTERVAL_PEAK / sin(progress × π)`
- 峰值时每20帧生成一个冰雹
- 冰雹随机x坐标生成（屏幕宽度范围内）
- 速度随机：5~8 px/帧
- 半径随机：4~8 px

**碰撞处理**：
- 冰雹碰撞走碰撞优先级链：统一护盾 > 冰晶护体 > HP扣血
- 碰撞后冰雹碎裂消失
- 冰晶护体可用时：冰雹转为护盾（+1层，不超过最大），冰晶护体进入CD
- 统一护盾可用时：消耗1层护盾，冰雹碎裂

**视觉效果**：
- 白色冰球下落（带轻微旋转和尾迹）
- 碰撞时碎裂特效（白色碎片四散+小粒子）
- 屏幕上冰雹密度随sin曲线变化

**玩家反馈**：
- 冰雹是唯一直接造成伤害的环境效果
- sin曲线密度让玩家有喘息窗口
- 冰晶护体能力可将冰雹转化为护盾资源
- 体魄的无敌帧也能抵御冰雹伤害

**数值**：
- 持续时间：10~20s（随游戏时间增长）
- 下落速度：5~8 px/帧
- 半径：4~8 px
- 峰值生成间隔：20帧

### 7.3 触发机制

#### 7.3.1 触发条件

```
游戏开始 → 30s前：不触发环境效果
         → 30s后：每10秒检查一次触发
                  → 计算当前触发概率
                  → 检查触发冷却（10s）
                  → 检查最大同时效果数（2个）
                  → 随机选择可触发的效果类型
                  → 检查该效果独立冷却（30s）
                  → 触发成功
```

#### 7.3.2 触发概率

- **起始时间**：游戏开始30s（1800帧）后开始检查
- **检查间隔**：每10秒（600帧）检查一次
- **基础概率**：20%
- **最大概率**：50%（10分钟/36000帧时达到）
- **概率增长**：线性增长

```
chance = BASE_CHANCE + (MAX_CHANCE - BASE_CHANCE) × Math.min(1, gameTime / CHANCE_RAMP_TIME)
```

#### 7.3.3 冷却机制

| 冷却类型 | 时间 | 说明 |
|----------|------|------|
| 触发冷却 | 10s（600帧） | 任意环境效果触发后，10s内不再触发新效果 |
| 效果独立冷却 | 30s（1800帧） | 同一效果触发后，30s内不再触发该效果 |

#### 7.3.4 最大同时效果数

- 同一时间最多 **2种** 环境效果同时活跃
- 当已有2种效果时，不再触发新效果（但已有效果可继续运行）
- 风暴之子能力在任意环境效果活跃期间生效

### 7.4 环境效果持续时间

| 效果 | 基础持续时间 | 说明 |
|------|-------------|------|
| 风 | 15~30s（900~1800帧） | 随游戏时间延长 |
| 雨 | 20~40s（1200~2400帧） | 随游戏时间延长 |
| 冰雹 | 10~20s（600~1200帧） | 随游戏时间延长 |

**持续时间计算**：
```
duration = MIN_DURATION + (MAX_DURATION - MIN_DURATION) × Math.min(1, gameTime / DURATION_RAMP_TIME)
duration ×= (1 - climate_adapt_reduction)  // 气候适应能力缩减
```

```javascript
class WindEffect extends WeatherEffect {
  constructor() {
    super('wind', '风');
    this.direction = 0;       // 风向角度
    this.isVertical = false;  // 垂直风 or 水平风
    this.currentForce = 0;    // 当前风力
  }

  onTrigger(gameCtx) {
    // 随机选择方向和类型
    this.isVertical = Math.random() < 0.5;
    this.direction = Math.random() < 0.5 ? 1 : -1;
    this.duration = this.getDuration(gameCtx.gameTime);
  }

  update(gameCtx) {
    this.elapsed++;
    // sin曲线风力
    this.currentForce = WEATHER.WIND.MAX_FORCE * this.sinIntensity * this.direction;
    // 应用风力
    if (this.isVertical) {
      gameCtx.bird.vy += this.currentForce;
    } else {
      gameCtx.scrollSpeed += this.currentForce;
    }
  }

  getDuration(gameTime) {
    const t = Math.min(1, gameTime / WEATHER.WIND.DURATION_RAMP_TIME);
    return WEATHER.WIND.MIN_DURATION + (WEATHER.WIND.MAX_DURATION - WEATHER.WIND.MIN_DURATION) * t;
  }

  render(ctx, screenW, screenH) {
    // 风向粒子线条 + 小鸟周围箭头
  }
}
```

#### 7.5.5 WeatherSystem 管理器

```javascript
class WeatherSystem {
  constructor() {
    this.activeEffects = [];       // 当前活跃的效果
    this.triggerCooldown = 0;      // 触发冷却计时器
    this.effectCooldowns = {};     // 各效果独立冷却 { wind: 0, rain: 0, hail: 0 }
    this.checkTimer = 0;           // 检查计时器
  }

  update(gameTime, gameCtx) {
    // 1. 检查触发
    this.checkTimer++;
    if (gameTime >= WEATHER.START_TIME && this.checkTimer >= WEATHER.CHECK_INTERVAL) {
      this.checkTimer = 0;
      this.tryTrigger(gameTime, gameCtx);
    }

    // 2. 更新活跃效果
    for (let i = this.activeEffects.length - 1; i >= 0; i--) {
      const effect = this.activeEffects[i];
      effect.update(gameCtx);
      if (effect.isExpired()) {
        effect.onExpire(gameCtx);
        this.effectCooldowns[effect.type] = WEATHER.EFFECT_COOLDOWN;
        this.activeEffects.splice(i, 1);
      }
    }

    // 3. 更新冷却
    if (this.triggerCooldown > 0) this.triggerCooldown--;
    for (const type in this.effectCooldowns) {
      if (this.effectCooldowns[type] > 0) this.effectCooldowns[type]--;
    }

    // 4. 雨效果结束后继续干燥
    this.handleRainDry(gameCtx);
  }

  tryTrigger(gameTime, gameCtx) {
    // 检查触发冷却
    if (this.triggerCooldown > 0) return;
    // 检查最大同时效果数
    if (this.activeEffects.length >= WEATHER.MAX_SIMULTANEOUS) return;
    // 计算触发概率
    const chance = WEATHER.BASE_CHANCE +
      (WEATHER.MAX_CHANCE - WEATHER.BASE_CHANCE) *
      Math.min(1, gameTime / WEATHER.CHANCE_RAMP_TIME);
    if (Math.random() > chance) return;
    // 选择可触发的效果
    const types = ['wind', 'rain', 'hail'];
    const available = types.filter(t =>
      !this.effectCooldowns[t] && !this.activeEffects.find(e => e.type === t)
    );
    if (available.length === 0) return;
    // 随机选择一个
    const type = available[Math.floor(Math.random() * available.length)];
    this.triggerEffect(type, gameCtx);
  }

  triggerEffect(type, gameCtx) {
    let effect;
    switch (type) {
      case 'wind': effect = new WindEffect(); break;
      case 'rain': effect = new RainEffect(); break;
      case 'hail': effect = new HailEffect(); break;
    }
    effect.onTrigger(gameCtx);
    this.activeEffects.push(effect);
    this.triggerCooldown = WEATHER.TRIGGER_COOLDOWN;
  }

  render(ctx, screenW, screenH) {
    for (const effect of this.activeEffects) {
      effect.render(ctx, screenW, screenH);
    }
  }

  getStatModifiers() {
    // 返回环境对属性的影响（供风暴之子能力使用）
    const modifiers = { gravity: 0, scrollSpeed: 0, allStats: 0 };
    if (this.activeEffects.length > 0) {
      // 风暴之子：环境期间全属性提升
      // 由AbilitySystem读取此值计算
    }
    return modifiers;
  }

  // 通知雨效果拍翅事件
  onFlap() {
    const rain = this.activeEffects.find(e => e.type === 'rain');
    if (rain) rain.onFlap();
  }
}
```

```javascript
  constructor(x, y, speed, radius) {
    this.x = x;
    this.y = y;
    this.vy = speed;
    this.radius = radius;
    this.rotation = 0;

    // 白色冰球 + 旋转 + 尾迹
  }
}
```

| 能力 | 交互对象 | 交互方式 |
|------|----------|----------|
| 顺风耳 | WindEffect | `windForce *= (1 - 0.3 * level)` |
| 雨衣 | RainEffect | `accumulationRate *= (1 - 0.4 * level)` |
| 冰晶护体 | HailEffect | 冰雹碰撞时，不扣血，+1护盾，进入CD |
| 御风者 | WindEffect | `windForce *= -1 * (1 + 0.5 * level)`（翻转方向+增强） |
| 气候适应 | 所有效果 | `duration *= (1 - 0.15 * level)` |
| 风暴之子 | 所有效果 | 环境活跃期间 `allStats *= (1 + 0.2 * level)` |

### 7.7 环境系统与游戏主循环集成

**复活动画细节**：
1. **暂停阶段**（60帧）：游戏暂停，画面定格，屏幕逐渐变暗
2. **火凤凰翅膀展开**（30帧）：
   - 小鸟背后展开一对橙红色半透明翅膀
   - 翅膀从中心向两侧展开（缩放动画）
   - 翅膀带有火焰粒子拖尾
3. **粒子爆发**（与翅膀展开同步）：
   - 橙红色粒子从小鸟位置向外爆发（16~24个粒子）
   - 粒子带重力衰减，向外散射后下落
   - 中心白色闪光（12帧）
4. **恢复阶段**：翅膀渐隐消失，HP恢复，游戏继续

**HUD凤凰印记计数**：
- 死亡前显示 `🔥×N`（N为剩余印记数）
- 位于HUD右上角等级徽章下方

### 8.5 特效系统架构设计

#### 8.5.1 特效基类

```javascript
class Effect {
  constructor(x, y, duration) {
    this.x = x;
    this.y = y;
    this.duration = duration;
    this.elapsed = 0;
    this.alive = true;
  }

  update() {
    this.elapsed++;
    if (this.elapsed >= this.duration) {
      this.alive = false;
    }
  }

  render(ctx) { /* 子类实现 */ }

  get progress() { return this.elapsed / this.duration; }
}
```

#### 8.5.2 特效管理器

```javascript
class EffectManager {
  constructor() {
    this.effects = [];  // 所有活跃特效
  }

  add(effect) {
    this.effects.push(effect);
  }

  update() {
    for (let i = this.effects.length - 1; i >= 0; i--) {
      this.effects[i].update();
      if (!this.effects[i].alive) {
        this.effects.splice(i, 1);
      }
    }
  }

  renderLayer(ctx, layer) {
    // 按层渲染：'hud' | 'environment' | 'player'
    for (const effect of this.effects) {
      if (effect.layer === layer) {
        effect.render(ctx);
      }
    }
  }
}
```

#### 8.5.3 Game.js 渲染调度

```javascript
// Game.render()
render() {
  // 1. 背景层
  this.renderBackground(ctx);

  // 2. 障碍层
  this.renderObstacles(ctx);

  // 3. 拾取物层
  this.renderCollectibles(ctx);

  // 4. 环境层（环境效果 + 环境层特效）
  this.weatherSystem.render(ctx, screenW, screenH);
  this.effectManager.renderLayer(ctx, 'environment');

  // 5. 特效层（擦边/粒子/光环）
  this.renderEffects(ctx);

  // 6. 小鸟层（玩家 + 玩家层特效）
  this.renderBird(ctx);
  this.effectManager.renderLayer(ctx, 'player');

  // 7. HUD层（UI + HUD层特效）
  this.renderHUD(ctx);
  this.effectManager.renderLayer(ctx, 'hud');
}
```
