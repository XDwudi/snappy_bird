## 1. 项目概述

### 1.1 一句话定位

> 一款融合 Flappy Bird 操控手感与 Vampire Survivors 式 roguelike 成长的小游戏生存游戏 —— 单指操作，越玩越强，每局都不一样。

### 1.2 核心体验

| 维度 | 设计目标 |
|------|----------|
| 操作 | 单指点击，0学习成本，3秒上手 |
| 单局时长 | 3~10分钟，适配碎片化场景 |
| 成长感 | 每局内获得15~25次升级选择，构筑流派 `[v1.1.0优化]` |
| 重玩性 | 能力随机组合 + 道具随机掉落 + 难度递增，每局体验不同 `[v1.1.0优化]` |
| 社交 | 好友排行榜 + 分享，轻社交驱动回流 |

### 1.3 核心循环

```
点击飞行 → 躲避障碍 → 收集经验/道具 → 升级选能力 → 变强生存 → 死亡重开
    ↑                                                              |
    └────────────────────────────────────────────────────────────┘
```

`[v1.1.0优化]` 核心循环新增「道具收集」环节，玩家在飞行过程中可拾取道具获得即时增益。

## 2. 核心玩法设计

### 2.1 基础飞行机制

沿用 Flappy Bird 经典手感，确保直觉操作：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 重力加速度 | 0.45 px/frame² | 每帧持续下落加速 |
| 点击上升力 | -8.0 px/frame | 单次点击施加的瞬间向上速度 |
| 最大下落速度 | 12 px/frame | 防止下落过快不可控 |
| 前进速度（世界滚动） | 3.0 px/frame | 障碍物向左移动速度，随时间增速 |
| 小鸟水平位置 | 固定在屏幕 1/3 处 | 小鸟X轴不动，世界左移产生前进感 |

### 2.2 障碍物系统 `[v1.1.0优化]` 面向对象重构

#### 2.2.1 架构设计

```
Obstacle (基类)
  ├── Pipe (标准管道) — 当前实现
  ├── MovingPipe (移动管道) — 预留接口
  ├── SpinningPipe (旋转管道) — 预留接口
  └── Spike (尖刺障碍) — 预留接口
```

基类定义统一接口：
- `update(speed)` — 更新位置
- `checkCollision(bird)` — 碰撞检测
- `render(ctx)` — 渲染
- `passed` — 是否已被通过（得分标记）

#### 2.2.2 基础障碍 — 管道

- 上下成对的管道，中间留有间隙供小鸟通过
- 管道从屏幕右侧生成，匀速左移至屏幕外销毁
- 每通过一对管道得 1 分 + 生成经验球/道具

| 难度阶段 | 间隙宽度 | 管道间距 | 滚动速度 | 持续时间 |
|----------|----------|----------|----------|----------|
| 新手期 | 220px | 320px | 3.0 px/f | 0~30s |
| 普通期 | 180px | 280px | 3.5 px/f | 30s~90s |
| 挑战期 | 150px | 240px | 4.0 px/f | 90s~180s |
| 极限期 | 130px | 220px | 4.5 px/f | 180s+ |

#### 2.2.3 进阶障碍类型（渐进引入）

| 类型 | 出现阶段 | 行为描述 | 设计意图 |
|------|----------|----------|----------|
| 标准管道 | 第0秒 | 固定位置，上下成对 | 基础难度 |
| 移动管道 | 第60秒 | 上下缓慢浮动 | 增加预判难度 |
| 旋转管道 | 第120秒 | 围绕中心点摆动 | 动态间隙变化 |
| 尖刺障碍 | 第150秒 | 顶/底部长出尖刺，间歇出现 | 限制安全区域 |

> **v1.1.0 范围**：实现标准管道 + OOP基类架构。移动管道等在后续迭代基于基类扩展。

### 2.3 碰撞判定 `[v1.1.0优化]` HP血条系统

#### 2.3.1 碰撞箱

- **小鸟碰撞箱**：略小于视觉尺寸（视觉尺寸的 70%），提升手感容错
- **碰撞对象**：管道、地面、天花板、障碍物

#### 2.3.2 `[v1.1.0新增]` 生命值系统

| 要素 | 设计 |
|------|------|
| 初始HP | 2 |
| 初始最大HP | 2 |
| 碰撞伤害 | 1点/次 |
| 受击无敌 | 碰撞后60帧(1s)无敌，小鸟闪烁特效 |
| 死亡条件 | HP降至0 |
| 地面碰撞 | 同样扣血（而非直接死亡） |
| 无敌期间 | 不再受碰撞伤害，可穿过障碍物 |

> **设计意图**：HP系统增加容错率，让玩家在失误后有恢复空间，同时配合道具和生命相关能力产生更丰富的策略选择。

#### 2.3.3 擦边奖励

- 小鸟穿越间隙时，若距管道边缘<15px，触发"擦边"特效 + 额外经验奖励
- 擦边奖励：经验+15、分数+3

### 2.4 经验与升级 `[v1.1.0优化]` 升级曲线调整

```
通过管道/拾取经验球/道具 → 经验条增长 → 经验条满 → 触发升级 → 暂停游戏弹出选择面板
```

| 要素 | v1.0.0 | v1.1.0 | 说明 |
|------|--------|--------|------|
| 经验来源 | 管道+5/球+10/擦边+15 | 同 + 道具经验包 | `[v1.1.0新增]`经验包道具 |
| 基础经验 | 20 | 18 | `[v1.1.0优化]`前期更快 |
| 每级增量 | +15 | +12 | `[v1.1.0优化]`曲线更平缓 |
| 单局升级次数 | 10~20 | 15~25 | `[v1.1.0优化]`更多选择机会 |

**经验阈值对比**：

| 等级 | v1.0.0 | v1.1.0 |
|------|--------|--------|
| 1→2 | 20 | 18 |
| 2→3 | 35 | 30 |
| 3→4 | 50 | 42 |
| 5→6 | 90 | 66 |
| 10→11 | 155 | 126 |
| 15→16 | 230 | 186 |

## 3. Roguelike系统设计

### 3.1 设计理念

借鉴 Vampire Survivors 的核心乐趣 —— **每局构筑不同流派**：

- 每局从零开始，无跨局养成（保证公平性）
- 单局内获得 15~25 次升级机会 `[v1.1.0优化]`
- 能力可叠加升级（同能力多次选择会增强）
- 能力等级上限提升，构筑深度增加 `[v1.1.0优化]`
- 能力之间存在隐性协同，玩家自主发现流派

### 3.2 能力体系 `[v1.1.0优化]` 扩展至22个能力

能力分为三大类：**被动强化**、**主动技能**、**特殊机制**。

### 3.3 升级选择面板交互

```
┌─────────────────────────────────┐
│          ⬆️ 升级! Lv.5           │
│      选择一项能力强化            │
├──────────┬──────────┬──────────┤
│  🪶 轻羽  │  🧲 磁吸  │ 🛡️ 护盾  │
│  Lv2→3   │  Lv1→2   │  Lv1→2  │
│ 降低重力  │ 吸引范围  │ 自动护盾 │
│  -8%     │ +50px    │ CD 25s  │
└──────────┴──────────┴──────────┘
```

- 游戏暂停，背景半透明遮罩
- 3张卡牌（拥有"幸运光环"后可扩展至4~6张）
- 点击卡牌 → 确认选择 → 面板收起 → 游戏继续
- 已满级能力不再出现在选项中
- 若所有能力均满级，升级改为"全属性 +5%"

### 3.4 能力随机规则

- 初始可选能力池：全部22个能力 Lv0 状态 `[v1.1.0优化]`
- 每次升级随机抽3个（未满级的能力）
- 抽取权重：未拥有能力(权重3) > 已拥有可升级(权重2)，鼓励尝试新能力
- 拥有"幸运光环"后，抽取数量 +1/级

## 4. 道具系统设计 `[v1.1.0新增]`

### 4.1 设计理念

道具是飞行过程中的即时增益物品，与能力系统形成互补：
- **能力** = 持久成长，整局生效
- **道具** = 即时效果，一次性或短时

### 4.2 道具类型

| 道具名 | 图标 | 颜色 | 效果 | 生成概率 | 设计意图 |
|--------|------|------|------|----------|----------|
| 经验包 | 📦 | 紫色 | 获得15~30随机经验 | 40% | 补充经验来源 |
| 血包 | 🩹 | 红色 | 恢复1点HP（不超上限） | 20% | 生存续航 |
| 护盾包 | 🛡️ | 蓝色 | 获得1层护盾，持续5秒 | 25% | 即时防护 |
| 速度包 | ⏱️ | 青色 | 3秒全局减速50% | 15% | 紧急避险 |

### 4.3 道具生成规则

- 通过管道时有 **25%概率** 生成道具（独立于经验球的70%概率）
- 道具生成位置：管道间隙中心
- 道具类型按上述概率随机
- 道具受 **磁吸能力** 影响吸引范围
- 道具拾取范围与经验球相同

### 4.4 道具拾取反馈

| 道具 | 拾取特效 | 音效（预留） |
|------|----------|-------------|
| 经验包 | 紫色粒子爆裂 + 浮动经验数值文字 | "叮" |
| 血包 | 绿色心形粒子 + HP图标闪烁 | "嘟" |
| 护盾包 | 蓝色光环扩散 + 小鸟护盾显示 | "嗡" |
| 速度包 | 青色波纹扩散 + 屏幕边缘青色边框 | "咻" |

### 4.5 OOP架构

```
Collectible (基类)
  ├── Orb (经验球) — 已有实现
  └── Item (道具)
       ├── type: 'exp_pack' / 'health_pack' / 'shield_pack' / 'speed_pack'
       └── 统一接口：update / checkCollect / isOffscreen / render
```

## 6. 技术方案

### 6.1 技术栈

| 选项 | 方案 | 结论 |
|------|------|------|
| **A** | 微信小游戏 + Canvas 2D | ✅ **当前采用** |

`[v1.1.0]` 项目已从小程序模式迁移至小游戏模式，所有UI通过Canvas 2D渲染，无WXML/WXSS。

### 6.2 性能设计

| 指标 | 目标 | 策略 |
|------|------|------|
| 帧率 | ≥30fps（目标60fps） | requestAnimationFrame 驱动、对象池复用、减少GC |
| 主包体积 | ≤5MB | 纯代码+像素风Canvas绘制，无图片素材 |
| 首屏加载 | ≤2s | 精简首屏资源 |
| 内存占用 | <100MB | 对象池、及时销毁离屏对象 |

### 6.3 渲染架构

```
┌─────────────────────────────────────┐
│           主 Canvas (游戏层)          │
│  ┌─────────────────────────────────┐│

│  ├─────────────────────────────────┤│
│  │  障碍层 (管道/障碍物) - 正速滚动  ││
│  ├─────────────────────────────────┤│
│  │  拾取物层 (经验球/道具) [v1.1.0]  ││
│  ├─────────────────────────────────┤│
│  │  小鸟层 (玩家+护盾+血条) [v1.1.0] ││
│  ├─────────────────────────────────┤│
│  │  特效层 (粒子/擦边/拾取效果)      ││
│  ├─────────────────────────────────┤│
│  │  UI层 (分数/经验条/HP/能力图标)   ││

│  └─────────────────────────────────┘│
└─────────────────────────────────────┘
```

### 6.4 `[v1.1.0新增]` 安全区适配

- 使用 `wx.getSystemInfoSync()` 获取 `safeArea` 信息

- 底部能力图标栏在 `safeArea.bottom` 上方渲染
