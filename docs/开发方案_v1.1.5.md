## 1. 项目概述

### 1.1 一句话定位

> 一款融合 Flappy Bird 操控手感与 Vampire Survivors 式 roguelike 成长的小游戏生存游戏 —— 单指操作，越玩越强，每局都不一样。

### 1.2 核心体验

| 维度 | 设计目标 |
|------|----------|
| 操作 | 单指点击，0学习成本，3秒上手 |
| 单局时长 | 3~10分钟，适配碎片化场景 |
| 成长感 | 每局内获得15~25次升级选择，构筑流派 |
| 重玩性 | 能力随机组合 + 道具随机掉落 + 稀有度概率 + 难度递增 |
| 视觉 | 像素复古风格，Canvas 2D 纯渲染 |

### 1.3 核心循环

```
点击飞行 → 躲避障碍 → 收集经验/道具 → 升级选能力 → 变强生存 → 死亡重开
    ↑                                                              |
    └────────────────────────────────────────────────────────────┘
```

### 1.4 技术栈

- 微信小游戏模式（非小程序）
- 纯 Canvas 2D 渲染，无游戏引擎
- 包体最小化，对象池 + 离屏Canvas优化
- 无 WXML/WXSS，所有UI通过Canvas绘制

## 3. 核心玩法设计

### 3.1 基础飞行机制

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 重力加速度 | 0.45 px/frame² | 每帧持续下落加速 |
| 点击上升力 | -8.0 px/frame | 单次点击施加的瞬间向上速度 |
| 最大下落速度 | 12 px/frame | 防止下落过快不可控 |
| 前进速度（世界滚动） | 3.0 px/frame | 障碍物向左移动速度，随时间增速 |
| 小鸟水平位置 | 固定在屏幕 1/3 处 | 小鸟X轴不动，世界左移产生前进感 |

### 3.2 障碍物系统

#### 3.2.1 OOP架构（v1.1.0）

```
Obstacle (基类)
  ├── Pipe (标准管道) — 当前实现
  ├── MovingPipe (移动管道) — 预留接口
  └── Spike (尖刺障碍) — 预留接口
```

基类定义统一接口：
- `update(speed)` — 更新位置（含v1.1.5缩小射线动画）
- `checkCollision(bird)` — 碰撞检测
- `render(ctx)` — 渲染
- `passed` — 是否已被通过（得分标记）
- `nearMissTriggered` — [v1.1.5] 擦边是否已触发（防重复）
- `shrinkBonus` / `currentShrink` — [v1.1.5] 缩小射线动画参数

#### 3.2.2 基础障碍 — 管道

- 上下成对的管道，中间留有间隙供小鸟通过
- 管道从屏幕右侧生成，匀速左移至屏幕外销毁
- 每通过一对管道得 1 分 + 经验 + 道具生成

| 难度阶段 | 间隙宽度 | 管道间距 | 滚动速度 | 持续时间 |
|----------|----------|----------|----------|----------|
| 新手期 | 220px | 320px | 3.0 px/f | 0~30s |
| 普通期 | 180px | 280px | 3.5 px/f | 30s~90s |
| 挑战期 | 150px | 240px | 4.0 px/f | 90s~180s |
| 极限期 | 130px | 220px | 4.5 px/f | 180s+ |

#### 3.2.3 缩小射线动画（v1.1.5新增）

- 拥有"缩小射线"能力时，管道间隙增大 +20px/级（v1.1.5: 15→20）
- 管道以基础间隙生成，两侧缓缓缩回至最终间隙（30帧动画）
- 上管道帽向上缩回，下管道帽向下缩回
- 动画期间碰撞检测同步更新，确保碰撞箱与视觉一致
- 动画在管道到达小鸟前完成（管道从屏幕右侧到小鸟约87帧）

### 3.3 碰撞判定

#### 3.3.1 碰撞箱

- **小鸟碰撞箱**：视觉尺寸的 70%，灵巧能力可进一步缩小12%/级
- **碰撞对象**：管道、地面、天花板

#### 3.3.2 生命值系统（v1.1.0）

| 要素 | 设计 |
|------|------|
| 初始HP | 2 |
| 初始最大HP | 2 |
| 碰撞伤害 | 1点/次 |
| 受击无敌 | 碰撞后60帧(1s)无敌 + 体魄加成 +30帧/级 |
| 死亡条件 | HP降至0 |
| 地面碰撞 | 同样扣血（而非直接死亡） |
| 无敌期间 | 不再受碰撞伤害，可穿过障碍物 |

#### 3.3.3 碰撞优先级链（v1.1.5更新）

```
无敌帧 > 时间扭曲 > 统一护盾(弹力护盾优先) > HP扣血 > 凤凰复活 > 死亡
```

**v1.1.5 变更**：弹力护甲（独立充能系统）和护盾（坚韧+道具）合并为统一护盾系统。碰撞时消耗一层护盾，若拥有弹力护盾则弹开，否则仅抵挡。

#### 3.3.4 擦边奖励（v1.1.5优化）

| 要素 | v1.1.0~v1.1.4 | v1.1.5 |
|------|---------------|--------|
| 触发距离 | 15px | **25px** |
| 触发时机 | 仅通过管道后检查一次 | **每帧检查（小鸟在管道x范围内时）** |
| 防重复 | 无 | **pipe.nearMissTriggered 标记** |
| 奖励 | 经验+15、分数+3 | 不变 |
| 视觉特效 | 多环扩散+8粒子+闪光（v1.1.4） | 不变 |

**设计意图**：原15px+仅通过后检查一次导致触发难度过高，玩家几乎无法感知。改为25px+每帧检查后，玩家在管道间隙中靠近边缘飞行即可触发，大幅降低难度。

### 3.4 经验与升级

```
通过管道/擦边/道具 → 经验条增长 → 经验条满 → 触发升级 → 暂停游戏弹出选择面板
```

| 要素 | 值 | 说明 |
|------|-----|------|
| 基础经验 | 18 | v1.1.0: 20→18 |
| 每级增量 | +12 | v1.1.0: 15→12 |
| 通过管道经验 | +10 | v1.1.4: 5→10 |
| 擦边经验 | +15 | 不变 |
| 经验包 | +15~30 | 随机 |
| 经验共鸣 | 20%/级概率双倍 | v1.1.4: 对所有经验生效 |

**经验来源（v1.1.4统一化）**：
- 通过管道：+10 EXP（经验球经验已移除，保留后续版本）
- 擦边通过：+15 EXP
- 经验包道具：+15~30 EXP
- 经验球：保留后续版本使用

所有经验获取通过统一方法 `_gainExp(baseExp, source, stats)`，确保经验共鸣对所有经验来源生效。

## 4. Roguelike系统设计

### 4.1 设计理念

- 每局从零开始，无跨局养成
- 单局内获得 15~25 次升级机会
- 能力可叠加升级，22个能力构筑深度
- 能力之间存在隐性协同，玩家自主发现流派

### 4.3 稀有度概率系统（v1.1.3）

4级稀有度，权重随玩家等级增长：

| 稀有度 | 基础权重 | 等级增长 | 权重上限 | 能力数量 |
|--------|----------|----------|----------|----------|
| 普通 | 10 | 0 | 12 | 2 |
| 稀有 | 6 | 0.2 | 10 | 10 |
| 珍贵 | 3 | 0.4 | 8 | 7 |
| 史诗 | 1.5 | 0.6 | 6 | 3 |

权重公式：`baseWeight × (1 + levelBonus × (playerLevel-1) / 10)`，钳制上限，新能力×1.3倍加成。

- 道具受磁吸能力影响
- 道具图标Canvas绘制独特形状（v1.1.4: 废弃emoji）

```
       ├── type: 'exp_pack' / 'health_pack' / 'shield_pack' / 'speed_pack'
```

## 6. 统一护盾系统（v1.1.5新增）

### 6.1 设计理念

v1.1.0~v1.1.4中存在三套独立的防护机制：
1. **坚韧护盾**（shields/maxShields）— 坚韧能力提供，30s恢复
2. **道具护盾**（itemShieldFrames）— 护盾包提供，5秒定时
3. **弹力护甲**（bounceArmorCharges/bounceArmorCD）— 独立充能+CD

v1.1.5将三者统一为**护盾层数系统**，简化逻辑、提升一致性。

### 6.2 核心机制

| 要素 | 设计 |
|------|------|
| 当前护盾层数 | `shieldLayers`，初始0 |
| 最大护盾层数 | `maxShieldLayers`，默认1 |
| 碰撞消耗 | 当前层数>0时，消耗1层 |
| 层数叠加 | 不超过最大层数 |
| 视觉区分 | N层 = N个同心圆圈环绕小鸟 |

### 6.3 护盾来源

| 来源 | 效果 | 恢复机制 |
|------|------|----------|
| 坚韧能力 | 最大护盾+1/级，选择时获得1层 | 30s恢复1层 |
| 弹力护盾能力 | 最大护盾+1/级，选择时获得1层 | (20-5*(lv-1))s恢复1层 |
| 护盾爆发能力 | 定期获得1层 | (25-3*(lv-1))s周期 |
| 护盾包道具 | +1层（不超过最大） | 无自动恢复 |

### 6.4 弹力护盾碰撞效果

当拥有弹力护盾且碰撞时：
1. 消耗1层护盾
2. 向碰撞反方向弹出（管道上侧→向下弹，管道下侧→向上弹）
3. 20帧无敌
4. 屏幕震动

### 6.5 最大护盾层数计算

```
maxShieldLayers = 1(默认) + 坚韧等级 + 弹力护盾等级
```

示例：
- 无能力：max=1
- 坚韧Lv2：max=3
- 坚韧Lv2 + 弹力护盾Lv1：max=4
- 坚韧Lv3 + 弹力护盾Lv3：max=7

## 7. 游戏系统总览

### 7.1 系统架构图

```
┌──────────────────────────────────────────────────────┐
│                    游戏主循环                          │
├──────────┬──────────┬──────────┬──────────────────────┤
│ 物理系统  │ 渲染系统  │ 碰撞系统  │  输入系统            │
│(重力/速度)│(Canvas绘制)│(AABB检测)│(触摸事件)            │
├──────────┴──────────┴──────────┴──────────────────────┤
│                    游戏逻辑层                           │
├──────────┬──────────┬──────────┬──────────┬───────────┤
│ 障碍生成  │ 经验系统  │ 能力系统  │ 道具系统  │ HP/护盾   │
```

## 8. 技术方案

### 8.1 性能设计

| 指标 | 目标 | 策略 |
|------|------|------|
| 帧率 | ≥30fps（目标60fps） | requestAnimationFrame驱动、对象池复用 |
| 主包体积 | ≤5MB | 纯代码+像素风Canvas绘制，无图片素材 |
| 首屏加载 | ≤2s | 精简首屏资源 |
| 内存占用 | <100MB | 对象池、及时销毁离屏对象 |

### 8.2 渲染架构

```
┌─────────────────────────────────────┐
│           主 Canvas (游戏层)          │
│  ┌─────────────────────────────────┐│
│  │  背景层 (天空/云/远景) - 慢速滚动 ││
│  ├─────────────────────────────────┤│
│  │  障碍层 (管道/障碍物) - 含缩回动画 ││
│  ├─────────────────────────────────┤│
│  │  拾取物层 (经验球/道具) - 独特图标 ││
│  ├─────────────────────────────────┤│
│  │  特效层 (擦边/粒子/光环)          ││
│  ├─────────────────────────────────┤│
│  │  小鸟层 (玩家+N层护盾圆圈)        ││
│  ├─────────────────────────────────┤│
│  │  UI层 (分数/经验条/HP/能力图标)   ││

│  └─────────────────────────────────┘│
└─────────────────────────────────────┘
```

### 8.3 安全区适配

- 使用 `wx.getSystemInfoSync().safeArea` 获取安全区
- 顶部HUD在 `safeArea.top` 下方渲染
- 底部能力图标栏在 `safeArea.bottom` 上方渲染
- `safeArea.bottom` 是Y坐标（从屏幕顶部算），直接用作safeBottom
- 无safeArea时回退固定偏移（top=12px, bottom=8px）

## 13. 稀有度概率系统（v1.1.3）

### 13.1 权重计算公式

```
weight = baseWeight × (1 + levelBonus × (playerLevel - 1) / 10)
weight = Math.min(weight, maxWeight)
if (currentLevel === 0) weight *= 1.3  // 新能力加成
```

2. **弹力护甲→弹力护盾**：
   - 最大护盾+1/级
   - 每(20-5*(lv-1))s恢复1层
   - 碰撞消耗1层护盾+向反方向弹开

3. **擦边触发优化**：
   - 距离 15→25px
   - 仅通过后检查→每帧检查（小鸟在管道x范围内时）
   - pipe.nearMissTriggered防重复

4. **缩小射线增强**：
   - 间隙增量 15→20px/级
   - 管道两侧缓缓缩回动画（30帧）

5. **完整开发方案归档**：
   - 在v1.1.0方案基础上整合v1.1.1~v1.1.5全部内容
